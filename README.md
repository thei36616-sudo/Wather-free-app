# Погода — Wather-free-app

Безкоштовний веб-застосунок погоди (PWA) у скляному стилі Glass з інтерактивною картою опадів, сповіщеннями про дощ, сніг і грозу та необов'язковою Android-оболонкою для екрана блокування й AOD (Samsung).

Інтерфейс натхненний порталом The Weather Channel, але проєкт із ним не пов'язаний. Дані, логотипи та торгові марки The Weather Company не використовуються.

Сторінка після ввімкнення GitHub Pages: `https://thei36616-sudo.github.io/Wather-free-app/`

## Можливості

**Погода**
- Поточна погода: температура, відчувається, вологість, вітер, тиск, УФ-індекс, схід і захід сонця.
- Прогноз на 24 години з інтерактивним графіком (проведіть пальцем чи мишею по кривій).
- Прогноз на 8 днів. Натисніть на день, і графік покаже цей день.
- Пошук міст по всьому світу з підказками, визначення місця за GPS, обрані міста (до 6), перемикач °C / °F.
- Автоматичне оновлення щохвилини. Інтерфейс перемальовується лише тоді, коли дані змінилися.

**Вигляд**
- Скляні панелі (Glass): напівпрозорий фон із розмиттям, світла рамка, м'які тіні.
- Анімації: плавні зміни кольору неба, хмари, дощ, сніг, зорі, блискавка під час грози, лічильник температури, поява карток. За системного налаштування «зменшити рух» анімації вимикаються.
- Сучасні лінійні SVG-іконки замість емодзі, у день і в ніч.
- Ранок, день, вечір і ніч розраховуються за сходом і заходом сонця в обраному місті. Є ручний перегляд кожної пори доби. Сонце й місяць плавно рухаються небом.

**Карта опадів**
- Радар опадів за останні 2 години (RainViewer) на карті OpenStreetMap, кнопка відтворення, повзунок часу.
- Торкніться карти, щоб побачити погоду в точці та назву місця. Кнопка «Прогноз тут» завантажує повний прогноз.
- Налаштування карти: підкладка (авто, світла, темна), колір радара, прозорість, швидкість анімації, згладжування, окремий колір снігу, мітка міста. Вибір зберігається.
- Режим збільшеної карти.

**Сповіщення**
- Попередження про дощ, сніг і грозу за 1, 3 або 6 годин наперед. Можна обрати, про що саме попереджати.
- Той самий вид опадів повторно сповіщає не раніше ніж через 3 години.
- Кнопка «Пробне» для перевірки.

**Додатково**
- Перевірка VPN: кнопка-щит у верхній панелі.
- PWA: встановлюється на головний екран, інтерфейс працює офлайн (потрібен інтернет для даних і карти).
- Android-оболонка: постійне сповіщення з температурою на екрані блокування й AOD, фонові попередження про опади.

## Структура репозиторію

```
index.html       застосунок (HTML, CSS і JS в одному файлі)
manifest.json    маніфест PWA
sw.js            сервіс-воркер: кеш, клік по сповіщенню
icon-192.png     іконка застосунку
icon-512.png     іконка застосунку
android-aod/     необов'язково: Kotlin-код для Android-оболонки
  MainActivity.kt
  WeatherWorker.kt
  README.txt
```

## Публікація на GitHub Pages

1. Покладіть файли `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` у корінь репозиторію, а не в підпапку.
2. Settings → Pages → Source: «Deploy from a branch» → гілка `main`, папка `/ (root)` → Save.
3. Зачекайте кілька хвилин і відкрийте `https://thei36616-sudo.github.io/Wather-free-app/`.
4. Після оновлення файлів перезавантажте сторінку двічі, бо сервіс-воркер кешує попередню версію.

## Встановлення на Android

**Варіант 1: PWA.** Відкрийте сайт у Chrome → меню ⋮ → «Встановити застосунок».

**Варіант 2: APK через PWABuilder.** Відкрийте pwabuilder.com, вставте адресу сайту, оберіть Package for stores → Android. Запити до карт йтимуть із вашого домену. У цьому APK немає нативного коду, тому постійного сповіщення для AOD і фонових попереджень не буде.

**Варіант 3: Android-оболонка з AOD і фоновими сповіщеннями.** Інструкція в `android-aod/README.txt`:
1. Android Studio → New Project → Empty Views Activity, пакет `com.example.weather`, Kotlin, Minimum SDK API 26.
2. Замініть `MainActivity.kt` і додайте `WeatherWorker.kt` з папки `android-aod`.
3. У `MainActivity.kt` замініть `YOUR-LOGIN` у `SITE_URL` на `thei36616-sudo`, а після `github.io/` вкажіть назву репозиторію: `https://thei36616-sudo.github.io/Wather-free-app/`.
4. У `build.gradle` додайте `implementation("androidx.work:work-runtime-ktx:2.9.1")`.
5. У `AndroidManifest.xml` додайте дозволи `INTERNET`, `POST_NOTIFICATIONS`, `ACCESS_COARSE_LOCATION`.
6. Build → Build APK(s).

### Samsung AOD

Samsung не дозволяє сторонні віджети на Always On Display. Тому застосунок показує постійне тихе сповіщення з температурою в значку. Що саме видно на AOD, залежить від налаштувань: Налаштування → Екран блокування та AOD, а також стиль сповіщень на екрані блокування («Значки» або «Докладно»). Для фонової роботи поставте застосунку «Акумулятор → Без обмежень».

## Налаштування і використання

- **Кнопка-щит** показує результат перевірки VPN. Натисніть на неї, щоб побачити деталі.
- **Кнопка-дзвіночок** відкриває налаштування сповіщень про опади.
- **Кнопка-телефон** з'являється лише в Android-оболонці й вмикає постійне сповіщення для екрана блокування.
- **Кнопка з повзунками на карті** відкриває налаштування карти.

## Джерела даних і умови використання

| Сервіс | Для чого | Примітки |
|---|---|---|
| [Open-Meteo](https://open-meteo.com) | Прогноз і геокодування міст | Без ключа. Безкоштовний для некомерційного використання з вказанням джерела. Перевірте поточні ліміти |
| [RainViewer](https://www.rainviewer.com/api.html) | Радар опадів | Безкоштовно лише остання пара годин, одна колірна схема, масштаб до 7. Колір у застосунку змінюється відтінком |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | Плитки карти | Потрібна атрибуція та коректний Referer. Не розрахований на високе навантаження |
| [Nominatim](https://operations.osmfoundation.org/policies/nominatim/) | Назва місця за координатами | Не частіше ніж 1 запит на секунду, результати кешуються, лише за дією користувача |
| [Leaflet](https://leafletjs.com) | Бібліотека карти | Завантажується з cdnjs, ліцензія BSD-2-Clause |
| [ipapi.is](https://ipapi.is), [ipwho.is](https://ipwho.is) | Перевірка VPN | Запасний сервіс лише порівнює часові пояси |

Адреси сервісів карти винесено в об'єкт `CFG` на початку коду, щоб їх можна було замінити без переписування застосунку. Якщо у вас буде багато користувачів, замініть публічні сервери OSM на платного провайдера або власний.

## Конфіденційність

- Застосунок не збирає й не надсилає дані на власний сервер, власного сервера немає.
- Запити йдуть до сторонніх сервісів із таблиці вище, тому вони бачать ваш IP. Для пошуку й прогнозу до Open-Meteo передаються координати міста.
- У `localStorage` зберігаються: одиниці виміру, останнє місто, обрані міста, пора доби, налаштування карти, налаштування сповіщень, час останніх сповіщень і кеш назв місць.
- Автооновлення щохвилини дає приблизно 1 440 запитів на добу від однієї відкритої вкладки.

## Відомі обмеження

- Перевірка VPN є здогадом, а не точним результатом. Сервіс може не побачити VPN, а різниця часових поясів може бути й без нього.
- У браузері сповіщення приходять, лише поки сторінка відкрита. Для фонових попереджень без сервера потрібна Android-оболонка.
- Мінімальний інтервал фонової перевірки в Android — 15 хвилин. Samsung може обмежувати фонову роботу.
- Користувач може змахнути постійне сповіщення. Воно повернеться після наступного оновлення.
- Радар показує лише минулі дві години, прогнозу руху хмар немає.
- Now Bar у One UI не використовується.
- Код Android-модуля не збирався й не запускався в автоматичному середовищі. Код веб-застосунку перевірено лише на синтаксис, тому перший запуск варто пройти вручну.

## Розв'язання проблем

| Проблема | Що робити |
|---|---|
| Сторінка 404 на GitHub Pages | Перевірте, що `index.html` лежить у корені репозиторію, а в Pages вибрано `main` і `/ (root)` |
| Помилка 403 на карті | Відкрийте сайт через HTTPS-хостинг, а не як локальний файл. У Android-оболонці сайт має завантажуватись із вашого домену |
| Після оновлення нічого не змінилося | Перезавантажте сторінку двічі, версію кешу зазначено в `sw.js` |
| Немає назви міста при кліку на карті | Nominatim міг відмовити. Тоді показуються координати, повтор можливий через годину |
| Немає сповіщень у браузері | Дозвольте сповіщення для сайту й натисніть «Пробне» у вікні дзвіночка |
| Збірка Jekyll падає на Pages | Додайте порожній файл `.nojekyll` у корінь репозиторію |
