# Погода — Wather-free-app

Безкоштовний веб-застосунок погоди (PWA) у скляному стилі Glass з інтерактивною картою опадів, сповіщеннями про дощ, сніг і грозу та необов'язковою Android-оболонкою для екрана блокування й AOD (Samsung).

Інтерфейс натхненний порталом The Weather Channel, але проєкт із ним не пов'язаний. Дані, логотипи та торгові марки The Weather Company не використовуються.

Сторінка після ввімкнення GitHub Pages: `https://thei36616-sudo.github.io/Wather-free-app/`

## Можливості

**Погода**
- Поточна погода: температура, відчувається, вологість, вітер, тиск, УФ-індекс, схід і захід сонця.
- Прогноз на 24 години з інтерактивним графіком (проведіть пальцем чи мишею по кривій).
- Прогноз на 8 днів. Натисніть на день, і графік покаже цей день.
- Пошук міст по всьому світу з підказками, визначення місця за GPS, обрані міста (до 6), перемикач °C / °F.
- Автоматичне оновлення щохвилини. Інтерфейс перемальовується лише тоді, коли дані змінилися.

**Вигляд**
- Скляні панелі (Glass): напівпрозорий фон із розмиттям, світла рамка, м'які тіні.
- Анімації: плавні зміни кольору неба, хмари, дощ, сніг, зорі, блискавка під час грози, лічильник температури, поява карток. За системного налаштування «зменшити рух» анімації вимикаються.
- Сучасні лінійні SVG-іконки замість емодзі, у день і в ніч.
- Ранок, день, вечір і ніч розраховуються за сходом і заходом сонця в обраному місті. Є ручний перегляд кожної пори доби. Сонце й місяць плавно рухаються небом.

**Карта опадів**
- Радар опадів і прогноз до 4 годин від Rainbow Weather на карті OpenStreetMap: кадри за останні 90 хвилин, поточний кадр і 6 кадрів прогнозу, кнопка відтворення, повзунок часу.
- Торкніться карти, щоб побачити погоду в точці та назву місця. Кнопка «Прогноз тут» завантажує повний прогноз.
- Налаштування карти: підкладка (авто, світла, темна), палітра радара (TWC, Rainbow, Dark Sky, NEXRAD, TITAN, синя), прозорість, горизонт прогнозу (1, 2 або 4 години), швидкість анімації, мітка міста. Вибір зберігається.
- Режим збільшеної карти.

**Сповіщення**
- Попередження про дощ, сніг і грозу за 1, 3 або 6 годин наперед. Можна обрати, про що саме попереджати.
- Той самий вид опадів повторно сповіщає не раніше ніж через 3 години.
- Кнопка «Пробне» для перевірки.

**Додатково**
- Перевірка VPN: кнопка-щит у верхній панелі.
- PWA: встановлюється на головний екран, інтерфейс працює офлайн (потрібен інтернет для даних і карти).
- Android-оболонка: постійне сповіщення з температурою на екрані блокування й AOD, фонові попередження про опади.

## Історія змін

Версії збігаються з назвою кешу сервіс-воркера в `sw.js`.

| Версія | Що змінилося |
|---|---|
| v1 | Перша версія: пошук, поточна погода, погодинний і 8-денний прогноз, GPS, °C/°F, PWA-маніфест, іконки |
| v2 | Стиль Glass, анімований фон, інтерактивний графік, обрані міста, лічильник температури |
| v3 | Сучасні SVG-іконки, перевірка VPN |
| v4 | Ранок, день, вечір, ніч; інтерактивна карта опадів (Leaflet + RainViewer, пізніше замінено на Rainbow Weather) |
| v5 | OpenStreetMap як підкладка, Nominatim для назв точок на карті, адреси сервісів у `CFG` |
| v6 | Запасна карта й підказки при помилці 403, явна політика Referer |
| v7 | Міст до Android-оболонки: постійне сповіщення для екрана блокування й AOD |
| v8 | Прибрано підкладку CARTO, лишилась лише OpenStreetMap; нічний режим карти через фільтр |
| v9 | Налаштування карти, автооновлення щохвилини, сповіщення про дощ, сніг і грозу |
| v10 | Радар на годину вперед: кадри прогнозу моделі Open-Meteo на таймлайні карти |
| v11 | RainViewer замінено на Rainbow Weather: палітри (зокрема TWC), прогноз до 4 годин, ключ або проксі, економне завантаження плиток |

## Структура репозиторію

```
index.html       застосунок (HTML, CSS і JS в одному файлі)
manifest.json    маніфест PWA
sw.js            сервіс-воркер: кеш, клік по сповіщенню
icon-192.png     іконка застосунку
icon-512.png     іконка застосунку
rainbow-proxy/   необов'язково: проксі-скрипт Cloudflare Worker для ключа Rainbow
  worker.js
android-aod/     необов'язково: Kotlin-код для Android-оболонки
  MainActivity.kt
  WeatherWorker.kt
  README.txt
```
